API

MorrisonMilbrandt2015.MorrisonMilbrandt2015 — Module
MorrisonMilbrandt2015

Condensation, evaporation, deposition, and sublimation of a homogeneous air parcel over a time step, after Morrison & Milbrandt (2015), Appendix C. tendencies returns the mean rates of an MM2015Problem with one of three schemes:

  • MM2015PiecewiseLinear: forward-Euler segments with rates frozen at each segment start.
  • MM2015FixedT: the exact solution of the frozen-coefficient problem.
  • MM2015: the parcel model solved numerically, with temperature evolving.

Thermodynamics.jl parameter sets serve as backends through a package extension.

MorrisonMilbrandt2015.MM2015 — Type
MM2015{FT}(; rtol, atol_q, atol_T, max_steps, root_finder, thresholds)
MM2015(; rtol, atol_q, atol_T, max_steps, root_finder, thresholds)

The parcel model solved by an exponential Rosenbrock integrator to relative tolerance rtol (default √eps(FT)), absolute tolerance atol_q [kg kg⁻¹] on liquid and ice (default 10⁻⁴ rtol), and absolute tolerance atol_T [K] on temperature (default 100 rtol), in at most max_steps steps, with events bracketed by root_finder and the state rounded by Thresholds thresholds. MM2015() is MM2015{Float64}().

source
MorrisonMilbrandt2015.Thresholds — Type
Thresholds(; x_min = 0, δ_min = 0, δ_i_min = 0)

Magnitudes below which a scheme rounds the state to its limit, in the moisture basis of the problem [kg kg⁻¹]: liquid or ice below x_min counts as absent and returns to the vapor during the step, and a supersaturation over liquid below δ_min or over ice below δ_i_min in magnitude counts as saturation. The defaults round nothing.

Thermodynamics from the host model

A host model that already holds the saturation humidities, latent heats, heat capacity, and density of the parcel passes them as ThermodynamicInputs to coefficients and calls tendencies(scheme, k::Coefficients, Δt) with MM2015FixedT or MM2015PiecewiseLinear.

MorrisonMilbrandt2015.Coefficients — Type
Coefficients(T, p, x_l, x_i, x_sl, x_si, δ, δ_i, Γ_l, Γ_i, α, τ_l, τ_i, A_l, below_triple)

Appendix C quantities of the parcel model at one state, in the moisture basis of the problem: temperature T [K], pressure p [Pa], liquid x_l and ice x_i, saturation humidities x_sl and x_si, the supersaturations δ = x_v − x_sl and δ_i = x_v − x_si, the factors Γ_l, Γ_i, α, the relaxation times τ_l and τ_i [s], the external forcing A_l [s⁻¹] of δ, and whether the parcel counts as below the triple point. The constructor adds Δ = x_sl − x_si, the rates r_l = 1/(τ_l Γ_l), r_i = 1/(τ_i Γ_i), k_l = 1/τ_l, k_i = α r_i [s⁻¹], k_lΔ = k_l Δ, k_iΔ = k_i Δ, and the relaxation times τ_ice_only = 1/k_i and τ_both = 1/(k_l + k_i) [s].

Coefficients at the state of problem, or of a state whose thermodynamics the host model supplies in inputs. The supersaturations over liquid δ and over ice δ_i [kg kg⁻¹] default to x_v − x_sl and x_v − x_si from the state; a host model that holds them passes them.

Thermodynamics backends

A backend is DefaultThermodynamicsBackend or, after using Thermodynamics, any Thermodynamics.Parameters.AbstractThermodynamicsParameters set. A new backend implements the constants R_d, R_v, cp_d, cp_v, cp_l, cp_i, grav, and T_triple, and the functions saturation_vapor_pressure and latent_heat. The package derives everything else from these.

MorrisonMilbrandt2015.DefaultThermodynamicsBackend — Type
DefaultThermodynamicsBackend()

Thermodynamics backend without dependencies, with fixed gas constants, heat capacities, gravity, and triple point. Its saturation vapor pressures integrate the Clausius–Clapeyron relation with latent heats that vary linearly with temperature (Kirchhoff), anchored at the triple point.

MorrisonMilbrandt2015.plot_step_change — Function
plot_step_change(problem, schemes, Δts; labels, reference = nothing) -> Figure

Change of liquid, ice, and their sum over one step of each of schemes for problem, against the step Δt for each step in Δts [s], on a symmetric logarithmic axis, with two guides: the change at the rate of the start of the step, and the loss of all of a phase. Color marks the phase and line style the scheme. reference = (; Δts, changes) adds the liquid and ice changes changes of a reference solution at its steps Δts as dots, and a panel with the difference of each scheme from it relative to the larger reference change. Requires using CairoMakie.

MorrisonMilbrandt2015.plot_step_change! — Function
plot_step_change!(position, problem, schemes, Δts; labels, reference = nothing, difference = true, ylimits = nothing) -> (; change, difference)

plot_step_change without its legend into the figure position position, returning the axes. The difference panel is drawn only when reference is given and difference holds; without it, the returned difference is nothing. ylimits = (lo, hi) sets the range of the change axis [kg kg⁻¹]. Requires using CairoMakie.
